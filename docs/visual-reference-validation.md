# v1.2 视觉参考更新验证

## 已执行

- 对一次真实用户提供的正向、反向参考做本地观察和章节映射；保留明暗、卡片等共享特征，未将其一律禁用。原图和个人偏好未进入此发行包。
- 同一案例保持既定浅色与品牌色，在既有原稿和事实范围内修改展示层；保留八章及第三方方向参考的归属。
- 实际页面在 Chrome 1440、820、390 px 检查无横向溢出、坏图或页面脚本错误；原图查看、关闭、焦点归还和导航通过。
- 对实际交付的离线单文件运行首页回归：两种输入顺序、刷新、非法协议、宽图、导出与再次导出、恢复通过；没有外部请求或脚本错误。
- Skill 元数据、相对链接与本地／公开素材边界检查。

个人案例输出不包含在此包中；上述观察不证明所有未来输出都达到同样质量。原有 T01–T04 是历史文本测试，T05 的通用组件未修改，不声称重跑其全部分支。
