# v1.1 首页自定义组件验证

## 执行范围

对仓库中自包含的 `assets/home-cover-editor.html` 进行真实浏览器执行。使用本地合成的纯色／几何 PNG 作为测试输入，未使用客户项目、设计稿或真实业务数据。验证环境为 Chrome，桌面 1440px 和手机 390px；其他浏览器未单独验收。

## 已执行的检查

| 检查 | 结果 |
| --- | --- |
| 图片格式与大小 | 非图片格式、超过8MB均有错误反馈 |
| 从本机选图与拖入 | 均可更新预览和应用到首页 |
| 编辑顺序 | 先填链接再选图、先选图再填链接均保留设置 |
| 本机持久化 | 应用后刷新仍恢复设置 |
| 案例隔离 | 不同 `data-portfolio-id` 不共享封面 |
| 链接边界 | 拒绝非 http／https 协议，保存时不访问外部设计文件 |
| 宽高比适配 | 宽图切换到单图展示且保留比例 |
| 离线导出 | 下载的 HTML 保留封面与设计链接 |
| 连续再导出 | 重开第一次导出文件后可再次导出，第二份文件的下载按钮仍可用 |
| 恢复原始封面 | 自定义导出文件也能恢复初始封面 |
| 原图与键盘 | 原图查看、Escape 关闭、焦点归还通过 |
| 手机布局 | 当前尺寸无横向溢出；编辑表单可打开 |
| 网络与运行错误 | 上传、保存及导出期间记录到的 http(s) 请求为0，页面脚本错误为0 |

验证包含了图片异步读取不覆盖链接、导出文件不残留忙碌／禁用按钮这两项回归条件。

## 结构与隐私检查

- 主文件元数据与名称、版本检查通过；主流程保留八项案例策划。
- 新组件和参考说明按需读取，未将上传控件强制加入纯文字策划或静态图片。
- 公开的通用组件中没有客户图片、品牌项目文案、个人绝对文件路径或个案作品集；仅含代码编写的占位封面。
- 原有 [v1.0 文本验证记录](validation.md) 保留为历史记录，本轮没有重跑或扩称四个项目的真实视觉验收。

## 验证边界

浏览器的本机存储可能因隐私模式、策略或空间限制失败，组件对此显示提示并保留下载方式。真实设计文件的可访问性和权限由原平台决定，本轮只验证入口和协议。生成的新作品集如引入其他字体、图片或脚本，需要重新检查其离线完整性；通用组件通过不等于所有未来生成页面自动通过。
