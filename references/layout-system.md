# PC 长页与 Figma 制作策划

## 阅读结构与节奏

先决定章节和证据，再分配画面面积，不固定页数或平均切块。

- 长案例可设左侧导航，用短名和稳定编号对应正文；短案例可不设。说明导航与内容区的关系，导航不重复长标题。
- 首屏给成果和定位，问题章给可比证据，核心解法用大图建立理解再用少量标注展开，应用章给情境，末尾交代结果边界。
- 主视觉、对比、细节、应用应有面积和密度变化，不把所有章变成同尺寸卡片。
- 一章一核心问题；图不足可合并叙事，不以装饰模块填满长页。

## 按证明目的选择版式

| 要证明什么 | 推荐布局 | 素材与阅读线索 |
| --- | --- | --- |
| 整体成果 | 宽幅主视觉／有主次的成果组图 | 定稿、定位和项目状态；主图缺失待补 |
| 新旧变化 | 同尺度左右或同位置上下对比 | 同任务／场景、版本标签、变化标注，不裁去不利信息 |
| 任务路径 | 横向步骤或分段纵向流程 | 入口、动作、反馈、必要分支，连线说明顺序 |
| 状态和动效 | 状态条／关键帧序列 | 触发、过程、结束及异常或返回；录屏旁给静态关键帧 |
| 品牌推导 | 依据—形态提取—定稿的连续构图 | 实际过程；后补推导标签可见 |
| 方案选择 | 等尺寸并列加精简比较 | 真实方向、同样本、选择维度、取舍，无依据不打分 |
| 视觉规则 | 大例图配规则标注与必要边界 | 网格、比例、颜色、材质或组合；说明用途的反例须标注 |
| 全量覆盖 | 类别／等级／状态矩阵 | 已有编号与覆盖缺口，保证识别尺寸 |
| 场景适配 | 场景总览加落点放大 | 实际应用、原型或样机标签及适配约束 |
| 结果与限制 | 证据摘要与精简复盘 | 数据口径或交付记录；无数据设建议验证区，不画假曲线 |

版式可组合，选择理由指向核心问题，不只说“更高级”。素材复用时标明不同裁切和证明目的，避免重复占幅。

## 每章交接信息

输出供 Figma 制作的信息，不生成节点或自动排版：

- 章节编号、导航名、核心问题、标题和正文。
- 主图／辅图／标注层级、阅读顺序及图文关系。
- 素材编号与位置，裁切、同尺度处理、放大或待制作示意。保留原稿，编辑建议不是已有素材。
- 密度（低／中／高）与前后章节奏。
- 必要的 Figma 组织建议，如纵向章节 Frame、统一对比容器、复用图注或状态单元。

用户有既定画板、网格、字体和规范则沿用。没有时可提出起始值，例如 1440 px PC 画板、独立导航区与内容栅格，但标为制作建议，随图片清晰度与文案调整；数字不是固定要求。不将前端框架或代码塞进策划。

## 素材不足

- 缺旧版：找真实旧稿，暂留待补对照位置，不重建虚假旧版。
- 缺录屏：有连续状态稿可策划关键帧；单图只列动效待确认项，不描述已存在动画。
- 缺应用：可建议做样机或场景示意，标为建议制作／概念演示。
- 缺全量：展示已知子集与覆盖范围，不复制变色凑数。
- 素材低清：换原图或调整尺度，关键判断须有可读证据。
