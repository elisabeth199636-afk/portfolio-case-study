# 展示审美方向：有主次的强视觉

本方向由用户提供的正反案例提炼，公开内容仅为可复用的观察与制作规则，不附原图，不代表对参考作品的客观评分。它是可选择、可覆盖的展示起点；用户当前的品牌、素材、偏好和阅读要求优先。没有素材支撑时不硬套造型。

## 正向：让成果与设计判断成为主角

| 方向 | 如何落实 | 检查什么 |
| --- | --- | --- |
| 有分量的标题 | 用明确观点和可读的字号形成层级；标题可参与构图，不能压住关键成果 | 首屏是否能同时识别项目和主要设计成果，而非只记住装饰字 |
| 大图与明确焦点 | 选择最能说明卖点的主稿，辅助图退一级；为需要细读的内容保留正视大图或原图入口 | 缩略浏览能否指出一个主角；细读时关键状态和文字是否可辨 |
| 有组织的成果组 | 根据同类、步骤、等级、状态或应用把资产成组；前后、大小与适度倾斜可用于成果总览 | 分组依据是否来自内容；重要信息有没有被遮挡，是否所有图都被缩小 |
| 能解释设计的卡片 | 卡片承载真实成果、步骤、方案或状态，图像与说明共同完成一件事 | 去掉边框后关系是否仍清楚；是否只是把段落机械包成小块 |
| 统一的材质与识别 | 使用用户已有的图标、3D、摄影、色彩或形态形成连续性；外层展示承托作品 | 是否把不同参考的颜色、字体、材质全部混在一起，或生造无关资产 |
| 有对比的章节节奏 | 大成果建立印象，正视比较解释选择，局部放大讲规则，安静段落收束 | 相邻章节为何换布局；疏密与尺度是否服务不同证明目的 |

## 反向：具体避开的问题

- **通用企业官网式堆模块**：作品集被反复的服务卖点、无关图标、营销大数字、见证和交替图文占满。修正为项目实际问题、选择与视觉证据，保留有必要的重复结构。
- **无主次的拼贴**：多色贴纸、装饰字、随机角度和碎图同时争抢注意力。修正为一个主角、可解释的分组与稳定阅读顺序；拼贴本身并非禁用项。
- **只有大标题、没有作品**：标题和留白把真实稿件挤成角落小图。修正为成果进入第一屏、证据获得足够展示面积。
- **素材墙与卡片墙**：为了显得丰富，把全部资产等大排列或层层套容器。先选择能支持主线的子集，再按整体、比较、细节与应用展开；全量矩阵只在证明体系覆盖时使用。

正反案例可能共享大标题、卡片、深色或渐变。区别须落在主次、内容、构图与证明目的，不能把这些单个特征直接等同于好坏。

## 可选构图方式

- **封面／成果总览**：宽幅标题配主成果，或主稿领先的成果组；是否重叠取决于信息能否遮挡，不固定三张或固定左右。
- **方案取舍**：同任务、同尺度并列，理由紧贴差异；不同方案的装饰不影响比较公平性。
- **流程／状态／视觉规则**：正视画面或关键局部配少量标注；需要读细节时不用倾斜代替说明。
- **资产与应用**：按类别成组或按场景展示落点；密度由覆盖证据决定，不靠复制变色凑数量。

## 深浅主题的边界

该方向支持深色、浅色及有根据的章节色场，不锁定某一配色。深色展示可用有层次的深色表面、清楚的前景文字与少量强调；浅色展示可用明亮底色、足够的文字对比与真实素材建立层次。渐变、3D、圆角和发光只有在作品或用户风格有依据时采用。

作品集外层改为深色，不等于原项目也改成深色；不要反相图片、抹去原方案的取舍理由，或声称这是项目新定稿。保留编辑／放大功能和状态可读性，并实际检查手机重排。

## 输出交接

在现有版式输出中写清选用的构图、主辅素材、阅读顺序、采用理由与可检查结果。拿不准的偏好标为推断；用户有更新要求时调整此方向，不要求其迎合内置规则。
