# 本地作品集首页自定义

## 何时使用

仅在用户要求实际 HTML 展示版式及首页换图／上传／设计文件链接时使用。只要求案例策划时不运行、不加载组件；只交付 PNG、PDF 或 Figma 静态版式时，不声称图片中的控件真的能上传。

用户尚未确定交付格式而上传功能确实影响结果时，说明它需要浏览器中的 HTML 载体，再确认关键格式；已明确要求本地 HTML 或沿用同一作品集时直接继续，不重复询问。

## 复用方式

[assets/home-cover-editor.html](../assets/home-cover-editor.html) 是自包含、无客户素材的可运行示例，包含本地选图、拖放、设计文件链接、本机保存、恢复默认和再次导出。它不是完整作品集页面，也不替代项目自身的叙事。

生成实际页面时，把案例策划和真实设计素材落实到页面；将组件的首页绑定、表单、CSS 和脚本一起整合，沿用用户的品牌与版式。源模板中的 `.hero-cover`、`.hero-art`、图片预览与编辑器 ID 共同构成绑定，改名时同时更新脚本，不能只复制一个上传按钮。

- 首页外层的 `data-portfolio-id` 应为当前案例设置稳定且独立的值，避免同一浏览器中不同项目共用封面。
- `#viewer-image` 初始内容保存原始封面；更换当前封面时不要覆盖恢复默认的基准。
- `#saved-config` 存放导出文件携带的设置；显式导出的配置优先于浏览器旧设置。
- 完整离线 HTML 应内嵌所需图片、样式和脚本。模板自身不依赖外部库；生成的新页面若新增外部资源，应一并处理后再宣称可离线使用。
- 普通设计文件链接只显示“查看设计文件”入口。它不会自动转为封面，不改变原平台文件的访问权限，不暗示已导入可编辑 Figma 节点。

## 功能合同

| 功能 | 行为与边界 |
| --- | --- |
| 上传／拖入图片 | 默认接收 PNG、JPG、WebP、GIF，最大 8MB；这些是示例起点，可按实际需要调整。校验格式、大小和是否可解码，失败时显示可操作错误 |
| 预览与应用 | 保留比例，不裁切关键设计内容；多图组合可按宽高比切换单图。换图不能覆盖仍在编辑的链接 |
| 设计文件链接 | 只接受 http／https，链接文案清楚，打开新页使用 `noopener noreferrer`；不在保存时自动访问目标文件 |
| 本机保存 | 组件使用 IndexedDB，按案例隔离。保存失败时保留当前预览，提示可下载 HTML；不假装已经持久保存 |
| 恢复默认 | 同时恢复原始封面和默认链接，且导出文件中也可再次恢复 |
| 下载修改版 | 携带当前图片与链接，重新打开后仍能编辑与再次下载。导出克隆内的忙碌／禁用状态必须复位；不能将“正在打包”永久写进文件 |
| 交互可达 | 有输入标签、键盘焦点、关闭／Escape 和错误反馈；手机可操作且不横向溢出 |

表单输入是草稿，应用与导出都要读取最新内容。避免图片异步读取完成后重新填充整张表单，覆盖用户刚输入的链接。

## 隐私与交付

上传指从本机选择并留在浏览器，不是上传服务器。组件不得擅自发送图片、素材路径或项目内容到 GitHub、分析服务或其他远端。开源发布只打包通用代码与无客户素材的示例；真实案例留在用户授权的位置。

生成版式后，给出本地文件及必要的使用说明。能力允许时可另导出完整 PNG、章节 PNG；图片已栅格化，不称为可编辑 Figma 图层。修改封面后下载的是 HTML，不声称已自动同步更新之前导出的静态 PNG。

## 验证后再交付

实际运行：先填链接再换图、先换图再填链接、拖放、非法链接／格式、应用后刷新、横竖图、恢复默认、导出后重开并连续再导出；检查第二份导出文件的按钮仍可用。

另测两个案例的保存隔离、桌面和手机尺寸、原图放大与键盘关闭，以及本地上传和保存期间没有外部请求。验证结果按实际范围报告，不能仅凭按钮存在就声称功能完成。
